# 🚀 NeuroForge

> Building a Deep Learning Framework and GPT-style Large Language Model from scratch.

## Vision

NeuroForge is a long-term project focused on understanding every component of modern AI by building it from first principles.

Instead of relying on existing frameworks, NeuroForge recreates:

- Tensors
- Automatic Differentiation (Autograd)
- Neural Networks
- Optimizers
- Transformers
- GPT-style Language Models

The primary goal is education, experimentation, and engineering excellence.
